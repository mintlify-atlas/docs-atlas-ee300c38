AnalogTools is an open-source toolkit for [AnalogJS](https://analogjs.org) applications. Each package is independently installable and solves a specific challenge in fullstack Angular development.

<Warning>
  AnalogTools is in early development. Breaking changes may happen frequently as APIs evolve. Pin to specific versions in production.
</Warning>

## Packages

<CardGroup cols={2}>
  <Card title="@analog-tools/auth" icon="lock" href="/auth/overview">
    OAuth 2.0/OIDC authentication using the Backend-for-Frontend pattern. Tokens are stored server-side only and never exposed to the browser.
  </Card>
  <Card title="@analog-tools/session" icon="cookie" href="/session/overview">
    Session management with HMAC-SHA256 signed cookies and pluggable unstorage backends including Redis and Cloudflare KV.
  </Card>
  <Card title="@analog-tools/inject" icon="syringe" href="/inject/overview">

  </Card>
  <Card title="@analog-tools/logger" icon="terminal" href="/logger/overview">

  </Card>
  <Card title="@analog-tools/generator" icon="wand-magic-sparkles" href="/generator/overview">

## How it fits together

The packages are designed to work together but are independently usable:

```
@analog-tools/auth (server-side BFF authentication)
    ├── @analog-tools/session  (session storage)
    ├── @analog-tools/inject   (dependency injection)
    └── @analog-tools/logger   (structured logging)

@analog-tools/auth/angular (Angular client integration)
    └── communicates with @analog-tools/auth via HTTP
```

<Steps>
  <Step title="Install the packages you need">
    Each package is independently published to npm. Install only what your project requires.
  </Step>
  <Step title="Initialize authentication (optional)">
    Use the Nx generator to scaffold auth middleware, Angular providers, and Vite config in one command.
  </Step>
  <Step title="Protect your routes">
    Configure `unprotectedRoutes` and let the middleware handle the rest — redirect to login, token refresh, and session validation are automatic.
  </Step>
  <Step title="Use Angular client services">
    Inject `AuthService` in your components to access reactive `isAuthenticated()` and `user()` signals with no extra setup.
  </Step>
</Steps>
